Room for privacy.

This website uses locally bundled fonts, images, and scripts. It includes no analytics, advertising scripts, tracking pixels, cookies, newsletter form, account backend, or browser storage.

Interactive examples

The website reads a same-origin static releases.json file to show available installers. It does not send operating-system information to a separate service. Clicking a download opens a GitHub-hosted release asset. The phone, Profile carousel, import illustration, and connection choices use synthetic content and temporary page state. They do not sign in, connect devices, read another browser, submit information, or save your selections.

External links

Links to GitHub, brand owners, and source collections open separate services with their own privacy policies. This website does not collect email addresses or send form submissions.

Hosting

This website is hosted on GitHub Pages. See GitHub’s privacy statement for its handling of hosting request metadata. This site does not add analytics or tracking scripts.

Crescent Browser and Hub

This notice covers the website. Crescent Browser, Crescent Mobile, and Crescent Hub are in development and will have their own release privacy documentation. Cookies and site storage never sync.
