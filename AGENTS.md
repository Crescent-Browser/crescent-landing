# Crescent landing

Use Crescent Browser, Crescent Hub, Crescent Cloud, and Crescent Mobile for the respective products. This repository is the public-facing landing source, not the browser implementation.

- Preserve Prism branding and local font licenses.
- Keep screenshots, illustrations, planned features and verified shipping features distinguishable. See docs/provenance.md.
- Never invent performance comparisons, security guarantees, completed Hub transport, release installers, or Windows/Linux readiness.
- Cookies and site storage never sync. No AI integrations or cloud article library.
- No analytics, third-party scripts, waitlist backend or tracking without an explicit request.
- Build with npm run build and verify with npm run check; browser-check responsive layouts and changed interactions.
- Do not deploy, buy a domain, change organization settings or alter the user’s browser data without explicit authorization.
